# v3.3.0 Session 3 — SimpleDip Strategy, Licensing, Bug Fixes (2026-03-30)

## Added
- **SimpleDip strategy** — buy X% below recent high, fixed TP/SL, no regression/adaptation
  - `Strategies/SimpleDip.hpp`: Init, Adapt (no-op), BuySignal
  - Config: `default_strategy=2` selects SimpleDip
  - Uses `entry_offset_pct` for dip threshold, `take_profit_pct`/`stop_loss_pct` for exits
  - No regime dependency — trades in all market conditions
  - First overnight session: W:13 L:5, 72% win rate, positive P&L
- **Strategy selector** — `default_strategy` config field (-1=regime auto, 0=MR, 1=Momentum, 2=SimpleDip)
  - Hot-reloadable: change in Settings panel, switches immediately
  - Visible in Settings panel under "Strategy" section
- **License validation skeleton** — `Licensing.hpp` with HTTPS check + machine fingerprint + 24h cache
  - `LICENSE_BYPASS` define for development builds
  - Reads key from `~/.foxml/license.key`
  - Caches to `~/.foxml/license.cache`
- **Cloudflare Worker** — `license-server/` with KV storage for license keys
  - Endpoints: /check (validate), /activate (Stripe webhook), /deactivate (device removal)
  - Device fingerprinting: max 2 devices per key
  - Stripe webhook: auto-create/expire keys on subscription events
- **Licensing plan** — `plans/licensing.md` with full architecture, Stripe integration, distribution

## Changed
- **TRENDING_DOWN no longer pauses buying** — MR/SimpleDip can trade bounces in downtrends
  - Only VOLATILE regime pauses buying (actual chaos, not tradeable)
  - Regime adjustment still tightens TP/SL for counter-trend entries
- **Regime detector no longer overrides manual strategy selection**
  - When `default_strategy >= 0`, regime detection runs for display only
  - Only `default_strategy=-1` allows regime auto-switching
- Strategy name display: shows "SIMPLE DIP" in Regime Signals panel and ANSI TUI

## Fixed
- **Unpause calling Adapt** — was feeding stale data into P&L regression
  - Split into StrategyDispatch (full, slow path) and StrategyBuySignal (signal-only, unpause/init)
- **Regime overriding manual strategy** — strategy_id was overwritten on every regime change
  - Now only auto-switches when default_strategy=-1
- **Snapshot struct incompatibility** — adding fields shifted binary layout, corrupting loaded snapshots
  - Delete `portfolio.paper.snapshot` after upgrading

## Known Issues
- Trade stats accumulate across sessions via snapshot, CSV is per-session
- Fees eating profits at tight TP% — widen TP to 4%+ recommended
