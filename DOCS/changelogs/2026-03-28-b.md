# v3.3.0 — ImGui GUI, EMA Gate, Tech Debt Cleanup (2026-03-28/29)

## Dear ImGui Native GUI

Replaces the two-window setup (ANSI TUI + matplotlib chart) with a single native
SDL2/OpenGL3 window. ANSI TUI preserved as fallback build.

### Build
```bash
cmake -B build_gui -DUSE_IMGUI_GUI=ON [-DLATENCY_PROFILING=ON]
cmake --build build_gui
cd build_gui && ./engine_gui
```

### Dashboard Panels (all dockable, rearrangeable)
- Header, Top Bar, Market Structure, Regime Signals, Buy Gate
- Portfolio, P&L, Risk, Config, Positions (proper table), Stats, Latency

### Price Chart
- TradingView-style fixed-width sliding window (configurable 30/60/120/240 candles)
- Candle interval selector (15s/30s/1m/5m)
- OHLCV candlesticks with separate wick/body coloring
- Y-axis auto-range with minimum 0.1% of price, expands for TP/SL, dollar formatting
- Overlays: VWAP, 20-period SMA, EMA (gate baseline), current price line
- Position overlays: entry (solid thick wheat), TP (dashed green), SL (dashed red)
- Partial exit pairs grouped: single entry line labeled `#0,1 $66686`
- Buy gate threshold: cyan dot-dash, distinct from position lines
- Trade markers from CSV: buy/sell triangles (green TP, red SL)
- Regime background shading: faint green=trending, faint red=volatile
- Hover tooltips: OHLCV + volume per candle
- Time labels (HH:MM) on X axis

### Volume Chart (separate dockable window)
- Log10 scale for differentiation at low values
- Buy/sell ratio coloring (green=buy dominant, red=sell dominant)
- Volume gate threshold line (cyan dot-dash)

### Equity Curve (separate dockable window)
- Cumulative P&L line with green fill above zero

### Trade History Panel
- Sortable table of all completed trades from CSV

### Engine Log Viewer

## EMA Gate (Proactive Entry)

Replaces the lagging rolling average with a fast EMA for gate price computation.
Gate reacts in 1-2 seconds instead of 3-5 seconds.

- Hot path: branchless EMA update every tick (~2-3ns, mask-based init)
- Config: `gate_ema_enabled=1`, `gate_ema_alpha=0.997` (configurable in GUI)
- Strategies unaware of feature flag — caller passes EMA or zero (rolling avg fallback)
- Rolling average preserved for regime detection (needs stability)
- EMA line shown on price chart (cyan) alongside SMA for comparison

- Adding a new strategy: one case per function instead of 3 switch statements

  stale data into P&L regression

### Settings Auto-Generation

- Adding a GUI-editable field: ONE line in the array
