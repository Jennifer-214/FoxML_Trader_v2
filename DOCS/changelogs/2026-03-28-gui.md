# v3.3.0 Session 1 — ImGui GUI (2026-03-28)

## Added
- Dear ImGui native GUI (`engine_gui` binary) with SDL2/OpenGL3
- Dockable dashboard panels: Header, Top Bar, Market Structure, Regime Signals, Buy Gate, Portfolio, P&L, Risk, Config, Positions, Stats, Latency
- Candlestick price chart with VWAP, SMA overlays, position lines, trade markers
- Volume chart with buy/sell ratio coloring
- Equity curve with cumulative P&L and per-trade markers
- FoxML Classic theme with transparent panels (matches Kitty/Waybar)
- C++ candle accumulator fed from engine's existing Binance websocket
- C++ trade reader for CSV buy/sell markers
- Settings panel with live config editing + hot-reload
- Hack Nerd Font + Noto CJK for kaomoji fox art
- Hyprland compositor rule for window opacity
- Default dock layout via ImGui::DockBuilder
- Keyboard controls (q/p/r/s) via same atomic flags as ANSI TUI
- SDL window title with live price + P&L

## Changed
- TUI sparklines removed (matplotlib chart replaces them)
- Matplotlib toolbar hidden to match terminal theme
- CMake: `engine_gui` target with `-DUSE_IMGUI_GUI=ON`
- imgui/implot compiled as static lib without LTO (faster builds)

## Fixed
- Chart Y-axis auto-zoom too tight — minimum 0.1% range + TP/SL expansion
- Candle bodies invisible with few data points — minimum 2px height
- Volume bars overflow plot area — added ImPlot clipping
