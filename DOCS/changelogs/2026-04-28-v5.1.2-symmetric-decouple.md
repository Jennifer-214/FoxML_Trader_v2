# v5.1.2 — Full symmetric data-plane decoupling + parity gate (2026-04-28)

Closes the v5.1.0 sub-plan completely. The original goal was: **all 3
callers (per_core_slow live, centralized live, backtest) use per-core
`slow_state` via shared helpers**. v5.1.0 only converted the
per_core_slow path; v5.1.2 finishes the job.

## What changed

### New helpers (in `ControllerEventLoop.hpp`)

```cpp
EventLoop_UpdateRollingStateOneCore(state, c, price, vol, ts, is_buyer_maker,
                                     depth_imb, depth_spread, depth_enabled);

EventLoop_UpdateRollingStateAllCores(state, ...same args minus c...);

EventLoop_UpdateEmaPriceAllCores(state, ema_price);

int rebuilt = EventLoop_RebuildAllParameters_PerCore(
    state, config, current_price, ts, book_imbalance,
    current_spread, current_mid_price);
```

`OneCore` writes `state.cores[c].slow_state` for one engine. `AllCores`
loops c=0..N. `_PerCore` rebuild iterates calling `RebuildOneCore` with
each engine's own slow_state pointers.

### Caller switchovers

| Caller | Path | Pushes | Rebuild |
|---|---|---|---|
| centralized | producer fan_out + slow-path body | `UpdateRollingStateAllCores` + per-core depth-history loop | `RebuildAllParameters_PerCore` |
| per_core_slow | per-core lambda | `UpdateRollingStateOneCore` (own c only) | `RebuildOneCore` direct |
| backtest | `ShardedBacktestDriver_RunTick` | `UpdateRollingStateAllCores` + `UpdateEmaPriceAllCores` | `RebuildAllParameters_PerCore` |

`ema_price` is always producer-written (per-tick) for live, driver-
written for backtest. Replicated to all N engines via the helper.

### Removed

12 `static RollingStats / RORRegressor / FPN / CumDeltaState / ... /
SpreadState` declarations from `EngineSharded_Run`. The old comment
("shared per-engine since these describe market state, not core state")
was the v4.3 design intent — superseded by per-engine ownership.

The legacy `EventLoop_RebuildAllParameters` shared-state wrapper is
still callable (used by the backtest driver's tests directly) but no
longer invoked from any production caller. Could be removed in a future
sweep.

### TUI snapshot reads engine-0 slow_state

`TUI_CopySnapshotSharded` was passed shared `rolling_short` /
`rolling_long`. v5.1.2 passes engine 0's `slow_state->rolling_short`
since all engines push at identical cadence with identical input — the
reads are equivalent.

Same pattern for the warmup permission gate (`rolling_short.count >=
min_samples`) and the legacy `EventLoop_TrailingSLRatchet` call (which
takes a single rolling ref). Both now read engine 0's slow_state.
