# v3.3.0 Session 2 — Chart Polish, EMA Gate, Tech Debt (2026-03-29)

## Added
- EMA gate: branchless hot-path EMA for faster gate response (1-2s vs 5s)
- EMA line on price chart (cyan, alongside SMA for comparison)
- Candle interval selector (15s/30s/1m/5m dropdown)
- Visible candles selector (30/60/120/240 dropdown)
- Trade history panel: sortable table from CSV
- Engine log viewer: tails engine.log with color-coded lines
- Volume gate threshold line on volume chart (cyan dot-dash)
- Regime background shading on price chart (green=trending, red=volatile)
- Current price horizontal line (wheat, 30% alpha)
- R² bars colored by trend direction (green=up, red=down)
- Version.hpp: single source of truth for version string
- Limits.hpp: centralized MAX_PORTFOLIO_POSITIONS, CANDLE_HISTORY_MAX
- Integration contracts in CLAUDE.md (what to update for each change type)
- Code standards document (plans/code-standards.md)
- Proactive gate plan (plans/proactive-gate.md)

## Changed
- Theme: slate-neutral backgrounds (#191819) replacing pink-tinted FoxML BG (#1a1214)
- Theme: warm gold borders, sharp corners matching waybar
- Settings: data-driven from field_defs[] array (one line per field, no manual struct)
- Strategy dispatch: consolidated to StrategyDispatch + StrategyBuySignal (two functions replacing three switch statements)
- Position chart labels: display index (#0,#1) matching table, not bitmap slot
- Partial exit pairs: single entry line labeled #0,1 instead of overlapping lines
- Line differentiation: entry=solid thick, TP=dashed green, SL=dashed red, gate=cyan dot-dash
- Volume chart: log10 scale for low-value differentiation
- Font: Hack Nerd Font Mono 18px + Noto CJK merged for Japanese glyphs
- Text size bumped from 15px to 18px

## Fixed
- Trade marker ghosts: only render within candle high-low range
- Unpause calling Adapt: fed stale data into P&L regression (now signal-only)
- Snapshot struct incompatibility: layout changes invalidate old snapshots
- ImGui default blue slider/checkbox colors: overridden with warm tones
- Missing slider grab/checkmark color overrides causing blue artifacts

## Known Issues
- Snapshot persistence across struct changes requires deleting old snapshot file
- Trade stats (W/L/buys) accumulate across sessions while CSV is per-session
