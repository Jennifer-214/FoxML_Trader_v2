# 2026-04-03 — v3.7.0: Backtest Suite Launch

## Shared (Engine + Suite)

### BuyGate heap overflow fix
- `OrderGates.hpp`: when order pool was full (all 64 slots), `__builtin_ctzll(~0ULL)` returned 64 (UB), writing past the array. Added `free_mask` guard — returns early when pool is full.
- `PoolAllocator.hpp`: same fix in `OrderPool_Allocate` — returns NULL when full.
- This was the root cause of the `free(): invalid size` crash in the backtest suite.

### sim_time field
- Added `time_t sim_time` to `PortfolioController` struct.
- Live engine: set to `time(NULL)` each tick (no behavior change).
- Backtest: set from historical tick timestamp (`timestamp_ms / 1000000`).
- Replaced all `time(NULL)` calls inside the controller with `ctrl->sim_time`:
  - `last_slow_time` (time floor for slow-path triggering)
  - `entry_time[]` (position hold duration)
  - `regime_start_time` (regime duration display)
  - Warmup time floor
- Timestamps in Binance aggTrades CSVs are microseconds, not milliseconds.

## Execution Engine

- `main.cpp`: set `ctrl.sim_time = time(NULL)` before `PortfolioController_Tick` — maintains identical live behavior.
- No other engine changes. All 279 tests pass.
