# v3.2.0 — v4 Signals, Refactor, and Architecture Cleanup (2026-03-28)

## Bug Fixes

- **Trailing SL floor invariant** — trailing TP/SL now enforces 2:1 min reward/risk
  ratio after ratchet adjustments. Only applies when SL is below entry price — once
  SL trails above entry (guaranteed win), no floor is needed. (MeanReversion.hpp, Momentum.hpp)

- **Exposure calc fix** — exposure gate and TUI display now use actual position market
  value (`Portfolio_ComputeValue`) instead of `starting_balance - current_balance`, which
  incorrectly included realized losses/fees as phantom exposure. (PortfolioController.hpp,
  EngineTUI.hpp)

## New Features

### VWAP Gate (Mean Reversion)
- Rolling VWAP computed in RollingStats via running-sum with eviction (same O(1) pattern
  as directional volume)
- MR buy signal gates on price being below VWAP by configurable offset
- `vwap_offset=0.001` in engine.cfg (0 = disabled)
- TUI shows VWAP price and deviation in regime signals section
- **Rationale:** Buying below VWAP = buying at a discount to where volume actually traded.
  Much better than the binary volume gate alone.

### Session Awareness
- Classifies UTC hour into Asian (00-07), European (07-13), US (13-20), Overnight (20-00)
- Per-session volume gate multiplier: wider gates in low-vol sessions, tighter in US session
- `session_filter_enabled=0` (disabled by default)
- TUI shows current session name and multiplier in header bar
- Reuses existing `time(NULL)` call — no extra syscall

### Adaptive Post-SL Cooldown
- Cooldown now optionally scales with market context at SL trigger time
- High R² downtrend = longer cooldown (orderly sell-off)
- Low R² or positive slope = shorter cooldown (flash spike, already recovering)
- Formula: `base_cycles + (extra_cycles * R² * is_negative_slope)`
- `sl_cooldown_adaptive=0` (disabled by default, uses fixed `sl_cooldown_cycles`)

### Partial Exits (Scaling Out)
- At fill time, position splits into two bitmap slots with different TP levels
- Leg A (50%): exits at TP1 (normal distance)
- Leg B (50%): exits at TP2 (tp2_mult * TP1 distance, default 2x)
- When leg A exits at TP, leg B's SL ratchets to entry price (breakeven = free trade)
- Uses existing bitmap infrastructure — each leg is a regular position slot
- `partial_exit_enabled=0` (disabled by default, requires max_positions >= 2)

### L2 Order Book Depth
- New `BinanceDepth.hpp`: subscribes to `@depth5@100ms` websocket stream
- Parses top-5 bid/ask levels, computes imbalance, spread, mid_price
- Runs on its own thread with double-buffered `BookSnapshot` (lock-free reads)
- Book imbalance gate: blocks buys when bid excess < threshold
- New `WebSocketUtil.hpp`: shared TCP/SSL/websocket functions extracted from
  BinanceCrypto patterns (reusable for any Binance stream)
- `depth_enabled=0` (disabled by default)
- Zero hot-path impact: engine reads snapshot on slow path only

## Refactoring

### Gate_Zero Helper
- Extracted the 5-line branchless gate mask pattern into `Gate_Zero()` in OrderGates.hpp
- Replaced 5 instances across MeanReversion and Momentum

## How to Test

### Verify basic operation (no new features enabled)
1. `cmake -B build && cmake --build build && ./build/controller_test`
2. Run engine with existing engine.cfg — should behave identically to v3.1.0
3. TUI should show "engine v3.2.0" and VWAP line in regime signals

### Enable VWAP gate
1. Set `vwap_offset=0.001` in engine.cfg
2. Run engine, watch regime signals section for `vwap: $XXXXX.XX  dev: +/-X.XXX%`
3. Buy gate should only fire when price is 0.1% below VWAP
4. Hot-reload with 'r' to adjust

### Enable session awareness
1. Set `session_filter_enabled=1` in engine.cfg
2. TUI header should show session name and multiplier: `US (0.8x)` or `ASIA (1.5x)`
3. Volume gate threshold should scale by session multiplier

### Enable adaptive cooldown
1. Set `sl_cooldown_adaptive=1` in engine.cfg
2. After a stop loss, TUI should show varying cooldown durations
3. Flash crash recovery: short cooldown. Orderly downtrend: long cooldown.

### Enable partial exits
1. Set `partial_exit_enabled=1` and `max_positions=3` (need >= 2 slots per entry)
2. Watch positions section — entries should show 2 positions at same price, different TPs
3. When TP1 hits, remaining position's SL should move to entry price

### Enable L2 order book
1. Set `depth_enabled=1` and `min_book_imbalance=0.10` in engine.cfg
2. Engine log should show depth websocket connection
3. TUI regime signals should show `book: +/-X.XX` after VWAP line
4. Buy gate should block when bid imbalance < 10%
