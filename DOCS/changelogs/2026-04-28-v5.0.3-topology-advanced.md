First of five v5.1 polish items. Closes the deferred advanced-features

## What's new

### New columns in Engine Topology > Per-engine threads

| Column | What it shows |
|---|---|
| **State** | `running` / `yield` / `parked` / `PAUSED` — coarse thread state |
| **Last cycle** | `Δus` since last completed cycle (drift indicator) |
| **Cycles** | Monotonic count of completed slow-path cycles |
| **Q** | Live OMS submit-queue depth (cap 32, warns at >16) |

### Per-engine Pause/Resume buttons

In `engine_arch=per_core_slow`, each row gains a `Pause` button. Click to
pause that engine's slow-path thread; click `Resume` to unpause. The
hot-path keeps reading params (now stale until resume), so positions
already open continue to be managed by their TP/SL. New entries paused
until resume.

Useful for:
- Debugging without killing the whole engine
- A/B testing strategies (pause one engine, observe the others)
- Investigating per-engine behavior under load

## Implementation

**Single-writer rule**: each `CoreContext::sp_*` field has exactly one
writer (the slow-path thread that owns this core in `per_core_slow`, or
the producer in `centralized` for cores it iterates). The GUI publish
reads with relaxed ordering and copies into TUISnapshot.

**Pause control**: `TUISharedState::paused_engines_mask` is a `uint16_t`
bitmap. GUI is single-writer per bit; per-core thread c is single-reader
of bit c only. Slow-path checks at top of loop:

```cpp
if (g_shared.paused_engines_mask & (1u << c)) {
    state.cores[c].sp_state.store(3);
    state.cores[c].sp_yield_count.fetch_add(1);
    std::this_thread::yield();
    continue;
}
```

This is checked **before** the reset-paper park and the cadence yield, so
`PAUSED` takes precedence in the State column.

## Invariant A added (CLAUDE.md)

> **Lifecycle Bitmap Single-Writer**: `TUISharedState::paused_engines_mask`
> bits are GUI-thread single-writer. Per-core slow-path thread c reads
> bit c only with relaxed ordering. Single-writer single-reader per bit
> means no atomic operations are needed beyond the volatile load.
